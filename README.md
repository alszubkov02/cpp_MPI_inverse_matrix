**Метод Жордана поиска обратной матрицы с выбором главного элемента по строке.**

Реализован с использованием параллельных вычислений на основе библиотеки MPI и блочного хранения матрицы для повышения производительности и эффективного использования кэш-памяти в распределённых вычислительных системах.

Блочное хранение предполагает разбиение матрицы на блоки фиксированного размера, которые последовательно располагаются в памяти каждого процесса. Это позволяет минимизировать количество промахов кэша при выполнении операций над строками и столбцами, так как данные, участвующие в преобразованиях, загружаются компактными порциями и многократно используются. Каждый блок представляет собой непрерывный участок памяти, что особенно важно при распараллеливании, поскольку процессы могут независимо обрабатывать различные блоки без конфликтов доступа.

Параллелизация организована на уровне распределения строк матрицы между процессами. После выбора главного элемента и нормирования ведущей строки, выполняемых с глобальной синхронизацией, каждый процесс отвечает за обработку своей группы строк. Процессы выполняют операцию вычитания ведущей строки, умноженной на коэффициент, из всех элементов соответствующих им строк, работая независимо друг от друга. При блочном хранении это означает, что каждый процесс обрабатывает блоки данных, закреплённые за его строками, что обеспечивает равномерную загрузку вычислительных узлов и эффективное использование иерархии памяти. Синхронизация между процессами осуществляется с помощью коллективных операций MPI, таких как широковещательная рассылка ведущей строки и сбор обновлённых данных после завершения обработки всех строк, перед переходом к следующему шагу алгоритма.

Алгоритмическая сложность метода остаётся O(n³), однако использование параллельных вычислений позволяет достичь значительного ускорения за счёт распределения нагрузки между несколькими вычислительными узлами. Пространственная сложность составляет O(n²) с учётом блочного представления, которое не увеличивает общий объём памяти, но улучшает локальность доступа и минимизирует объём передаваемых данных между процессами. Выбор главного элемента по строке гарантирует численную устойчивость метода, а блочное хранение и распределённая обработка делают его эффективным для матриц большой размерности, позволяя достичь высокой производительности в многопроцессорных кластерных системах.
